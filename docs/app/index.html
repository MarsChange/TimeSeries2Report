Starting TimeSeries2Report…

Downloading the Python runtime and scientific packages. First launch can take a few minutes; keep this tab open.

Once loaded, open Model Settings and enter your own API key, HTTPS Base URL and model name. The endpoint must permit browser cross-origin (CORS) requests. An included example report can be viewed without an API key.
