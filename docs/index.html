Get started

Your data.
Your model endpoint.

Launch the application in your browser with Stlite, or run it locally with Python and Streamlit.

  1. Clone the repository and install its dependencies.
  2. Configure your provider in .env or open Model Settings in the app's left sidebar.
  3. Upload battery_time_series_for_test.pickle, then select Process File.

The browser edition runs Python on your device and requires a CORS-enabled model endpoint. Load the included example report to explore without an API key. Use only trusted Pickle files; model requests send report context to your configured provider.
